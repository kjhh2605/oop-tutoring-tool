# Java 튜터링 실시간 편집기

튜터 노트북에서 서버를 띄우면, 같은 Wi-Fi에 있는 튜티들이 브라우저로 접속해 Java 코드를 작성합니다.
튜터는 모든 튜티의 화면을 실시간으로 보다가, 원하는 튜티로 전환해 **튜티의 코드에 직접 타이핑**할 수 있습니다.

- 튜티 화면: 클래스별 파일 탭, Java 하이라이트·자동 들여쓰기, 실행 콘솔(`Scanner` 입력 지원)
- 튜터 화면: 튜티 카드 2×2 대시보드(실시간 미리보기) → 클릭 또는 `Alt+1~4`로 들어가 바로 편집, `Esc`로 복귀
- 튜티가 다른 클래스 파일로 이동하면 튜터 화면도 함께 이동합니다("튜티 따라가기", 끌 수 있음).
- 튜터가 입력한 부분은 튜티 화면에 **주황색으로 표시**되고, 튜티가 "튜터 수정 확인 ✓"을 누르면 지워집니다.
- 튜터가 보고 있으면 튜티 화면에 "👀 튜터가 보고 있어요"가 뜨고, 튜터 커서가 "튜터" 라벨과 함께 보입니다.
- 실행 결과와 입력은 튜티와 튜터 화면에 동시에 보이며, 튜터가 대신 입력하거나 중지할 수 있습니다.
- 튜터가 **📋 문제 게시**에서 문제 이미지를 붙여넣기(⌘/Ctrl+V)·끌어다 놓기·파일 선택으로 올리고 게시하면, 모든 튜티 화면 왼쪽에 바로 뜹니다. 한 문제에 여러 장을 넣을 수 있고(세로 스크롤), 이미지를 클릭하면 크게 볼 수 있습니다. 패널은 접거나 너비를 조절할 수 있습니다.
- 코드는 자동 저장되며 서버를 재시작해도 유지됩니다. 같은 이름으로 다시 들어오면 작성하던 코드가 열립니다.

## 준비물 (튜터 노트북만)

- Node.js 20 이상
- JDK 17 권장: `brew install --cask temurin@17`
  - JDK 17이 없으면 설치된 더 높은 JDK로 `javac --release 17` 컴파일합니다. Java 17에 없는 문법은 컴파일 에러로 막히고, 실행만 해당 JDK 런타임에서 됩니다.
  - 특정 JDK를 지정하려면 `JAVA17_HOME=/path/to/jdk-17` 환경 변수를 씁니다.

튜티 노트북에는 아무것도 설치할 필요가 없습니다(브라우저만 있으면 됩니다).

## 실행

```bash
npm install
npm start
```

터미널에 다음 정보가 출력됩니다.

```
 튜티 접속 주소 (같은 Wi-Fi):
   http://192.168.0.12:3000
 튜터 화면:  http://192.168.0.12:3000/tutor
 튜터 코드:  4172
 Java:       17.0.12 (java_home)
```

1. 튜터는 `/tutor` 주소로 들어가 **튜터 코드**를 입력합니다. 코드는 `data/config.json`에 저장되어 재시작해도 같습니다.
2. 튜티는 접속 주소로 들어가 **이름**을 입력합니다.

### 단축키

| 키 | 동작 |
|---|---|
| `Ctrl/⌘ + Enter` | 실행 |
| `Alt + 1~4` (튜터) | N번째 튜티로 바로 이동 |
| `Esc` (튜터) | 대시보드로 돌아가기 |
| 탭 더블클릭 | 파일(클래스) 이름 변경, `class` 선언도 함께 바뀜 |

## 문제 해결

- **튜티가 접속이 안 될 때**
  - 학교나 카페 Wi-Fi가 기기 간 통신을 막아 둔 경우(클라이언트 격리)가 많습니다. 튜터 휴대폰 핫스팟에 모두 접속한 뒤 서버를 다시 실행하고, 새로 출력된 주소를 쓰세요.
  - macOS에서 처음 실행할 때 "들어오는 연결 허용" 창이 뜨면 **허용**해야 합니다.
- **튜터 코드를 잊었을 때**: 서버 시작 로그에 다시 출력되며, `data/config.json`에도 있습니다. 직접 정하려면 `TUTOR_CODE=1234 npm start`로 실행합니다.
- **포트를 바꿀 때**: `PORT=4000 npm start`
- **잘못 입력한 이름 정리**: 튜터 대시보드 카드의 `×` 버튼으로 목록에서 지웁니다(코드 파일은 서버에 남습니다).
- **전체 초기화**: 서버를 끄고 `data/` 폴더를 지웁니다.
- **실행 제한**:
  - 프로그램 하나는 최대 5분까지 실행되고(`RUN_TIMEOUT_SEC`로 변경), 출력은 200KB까지입니다.
  - 무한 루프는 **■ 중지**로 멈출 수 있습니다.

> 튜티 코드는 튜터 노트북에서 실행됩니다(임시 폴더, 메모리 256MB, 시간 제한). 신뢰할 수 있는 수업 환경을 전제로 합니다.

## 개발

```bash
npm run dev        # 서버(3000) + Vite 개발 서버(5173, 핫 리로드). 접속은 5173 포트로
npm test           # 서버 통합 테스트 (동기화, 권한, 멀티 파일 컴파일, Scanner 입력, 에러, 중지, 재시작)
npm run e2e        # 브라우저 E2E (튜터 1 + 튜티 2, 로컬 Google Chrome 사용). 스크린샷은 .tmp-e2e/
npm run typecheck
```

구성:

```
server/   Hocuspocus(Yjs WebSocket) 서버, 인증, 저장(data/), Java 실행기
web/      React + CodeMirror 6 클라이언트 (튜티 화면 /, 튜터 화면 /tutor)
shared/   서버와 클라이언트가 함께 쓰는 문서 구조와 메시지 타입
docs/     계획서
```
